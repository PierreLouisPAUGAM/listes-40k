# Sources brutes

Déposer ici les documents officiels : PDF des règles, Faction Packs, extraits de
l'Inventaire du Munitorum, captures de l'appli.

Nommer les fichiers avec leur date ou leur version, par exemple
`munitorum-space-marines-v1.4.pdf` ou `appli-section-25-2026-09-21.png`.

Ces fichiers ne sont pas lus systématiquement : ils servent de référence quand une donnée
doit être vérifiée ou réextraite.
