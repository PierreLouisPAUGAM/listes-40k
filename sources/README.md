# Sources brutes

Déposer ici les documents bruts : PDF des règles, Packs de Faction, pages de l'Inventaire
du Munitorum, captures de l'appli.

Nommage, en-tête des fichiers dérivés et procédure de veille : voir `procedures.md`.
Exemples : `munitorum_tyranides_v1.5_fr_2026-10-06.html`,
`appli-s25_general_sv_fr_2026-09-21-01.png`.

Ces fichiers ne sont pas lus systématiquement : ils servent de référence quand une donnée
doit être vérifiée ou réextraite.
